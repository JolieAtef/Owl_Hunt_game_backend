# Owl Hunt Game Backend API

A RESTful API backend for the Owl Hunt game, providing user management, score tracking, and leaderboard functionality.

## 🎮 Project Overview

This backend service powers the Owl Hunt game by managing player data, tracking scores, and maintaining a competitive leaderboard. The API is built with Node.js and Express, using MongoDB for persistent data storage.

## ✨ Features

- **Player Registration**: Register new players with customizable difficulty levels
- **Score Tracking**: Update and maintain player scores
- **Leaderboard System**: Retrieve top 5 players ranked by performance
- **CORS Support**: Configured for seamless frontend integration
- **Environment Configuration**: Secure configuration management
- **Deployment Ready**: Optimized for Vercel deployment

## 🛠️ Tech Stack

- **Runtime**: Node.js (ES Modules)
- **Framework**: Express.js 5.2.1
- **Database**: MongoDB with Mongoose ODM 9.3.1
- **Security**: CORS 2.8.6
- **Configuration**: dotenv 17.3.1
- **Deployment**: Vercel
